# Tally — Swift Playgrounds

This repository is a standalone Swift Playgrounds app project for **Tally**.

## Open on iPhone or iPad

1. Open the repository in GitHub.
2. Download the repository as a ZIP and extract it in the Files app.
3. In Swift Playgrounds, choose **Browse / Open** and select the folder containing `Package.swift`.
4. Open the **Tally** app project and run it.

The project targets iOS 26 and supports iPhone and iPad. Counters and history are stored locally on the device.

## Playground edition

This is a standalone Playgrounds target. It is generated from the complete source of the original Tally app, while Xcode-only signing/extension integration remains excluded by the source's existing conditional compilation guards.

The original Tally repository remains unchanged.
